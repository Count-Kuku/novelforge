# NovelForge v0.7.1

发布日期：2026-08-04

## 版本定位

`v0.7.1` 是自由创作工作台上线后的稳定性与发布质量修复版，重点改善不可用操作的视觉表达，并加固 Windows 便携版构建流程。

## 主要变化

- 保留“生成片段”等主操作的蓝色强调样式，同时将不可用的主按钮统一改为中性灰色禁用态，避免它们看起来仍像可以点击。
- 为自由创作页补充按钮样式回归检查，确保主操作层级和禁用态不会在后续 UI 调整中退化。
- 发布脚本现在以仓库 `VERSION` 文件作为版本唯一来源；显式传入不一致的版本号时会停止构建，避免压缩包名称与包内版本不一致。
- Windows 便携版构建完成后自动生成 SHA-256 校验文件，便于验证下载或复制后的压缩包完整性。
- 运行时复制完成后统一清理 Python 缓存和临时文件，减少便携版中无用内容。
- 便携版补齐 `storage_architecture.md`，避免项目文档引用的存储架构说明在发布包中缺失。

## 审查与验证

本次发布执行了以下检查：

- 全项目 Python 字节码编译与依赖一致性检查
- 包结构、UI 一致性、自由创作界面回归检查
- 生成工作流保护、统一上下文组装与交互式写作验证
- SQLite 存储、故事隔离、原子写入、复制/删除语义与应用导入冒烟验证
- 启动器锁、端口状态与发布路径/版本防护验证
- Windows 便携版构建、包内依赖导入、HTTP 启动冒烟与 SHA-256 校验
