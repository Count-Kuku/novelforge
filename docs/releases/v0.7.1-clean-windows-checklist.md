# v0.7.1 干净 Windows 发布验收清单

这份清单用于关闭 `VF-7.5`、真实 provider/IME 和兼容窗口门槛。它必须在未安装 Node.js、未使用开发工作区的 Windows 机器上执行；本地临时 root 夹具不能替代本清单。

## 机器与包

- [ ] Windows 10/11、普通用户权限、无 Node.js/ npm。
- [ ] 下载 `NovelForge-windows-portable-v0.7.1.zip` 与同目录 `.sha256`，校验 SHA-256 后再解压。
- [ ] 解压路径不含旧版本残留；确认 `.runtime/python.exe`、`NovelForge.exe`、`frontend/dist/index.html` 存在。

## Launcher 矩阵

- [ ] 双击 `NovelForge.exe`：默认进入 Vue 模式，浏览器打开 `127.0.0.1:8501`，页面显示规划/对话双入口。
- [ ] 检查 `launcher.log`、`.novelforge-server.json`；日志不包含 API Key 或完整请求正文。
- [ ] 在 8501 被其他程序占用时启动：自动回退到 8502，并记录冲突端口。
- [ ] 在已有 NovelForge 实例运行时再次启动：复用已有页面，不创建第二个服务。
- [ ] 创建一个项目和两种故事，关闭进程后重新启动：项目、故事、模式和章节资产仍存在。
- [ ] 删除/移动 `.novelforge-server.json` 后再次启动：不会误杀其他 PID，陈旧状态会被清理。

## 真实 provider 与输入法

- [ ] 在设置页配置真实 provider；执行一次普通生成和一次 SSE 长流，记录模型名、耗时、失败/重连结果，不记录密钥。
- [ ] 通过代理或短暂网络断开制造一次流中断：页面可恢复 operation 状态，不重复创建写入。
- [ ] 使用系统中文输入法完成组合输入、候选词确认、Ctrl/⌘+Enter；组合状态期间不得误发送。
- [ ] 粘贴/编辑长正文和长会话，确认移动视口无横向溢出、刷新后草稿/会话可恢复。

## 兼容窗口

- [ ] 在至少一个明确窗口内保留 `NOVELFORGE_FRONTEND=streamlit` 回退，记录 Vue 与 Streamlit 的关键业务对等结果。
- [ ] 窗口结束后复核无未解决阻塞项，再按迁移规划执行 VF-8.5，删除 Streamlit renderer、依赖和回退 guard。

验收记录应附：日期、Windows 版本、包 SHA-256、浏览器版本、provider 类型（不含密钥）、失败日志摘要和执行人。
